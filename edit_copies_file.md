# Изменить количество копий файла

Метод редактирует количество копий файла в заказе или ASN.

POST `https://apiamb.kosmoslogistic.ru/api?command=edit_copies_file`

## Заголовки

| Заголовок     | Значение         |
|---------------|------------------|
| Content-Type  | application/json |
| Authorization | `<your-token>`   |

## Тело запроса

```json
{
  "file_ref": 123,
  "copies_count": 2
}
```

## Параметры запроса

| Параметр      | Обязательный | Описание |
|---------------|--------------|----------|
| `file_ref`    | Да           | Идентификатор файла в `FilesOrder` (`ref`). |
| `copies_count`| Да           | Количество копий для файла. Должно быть больше `0`. |

## Что делает метод

1. Проверяет токен авторизации.
2. Проверяет, что токен не ограничен режимом только просмотра (`tokenLimited`).
3. Находит клиента по токену и проверяет его существование.
4. Находит файл по `file_ref`.
5. Проверяет, что файл принадлежит клиенту либо через заказ, либо через ASN.
6. Обновляет число копий файла через `PutCopiesCount(copies_count)`.

## Успешный ответ

### 200 OK

```json
{
  "result": "OK"
}
```

## Ошибки

### 401 Unauthorized

Токен не был передан.

```json
{
  "error": "access_denied",
  "message": "Токен не задан."
}
```

### 403 Forbidden

Токен недействителен или не прошёл проверку доступа.

```json
{
  "error": "access_denied",
  "message": "<текст ошибки проверки токена>"
}
```

```json
{
  "error": "error",
  "message": "Не задано количество копий!"
}
```

```json
{
  "error": "error",
  "message": "Файл не найден!"
}
```

### 404 Not Found

Клиент, связанный с токеном, не найден.

```json
{
  "error": "error",
  "message": "Клиент не найден"
}
```

### 501 Not Implemented

Токен используется только для просмотра и не может изменять количество копий.

```json
{
  "error": "error",
  "message": "Только просмотр!"
}
```
